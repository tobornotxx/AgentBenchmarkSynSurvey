# EnvScaler: Scaling Tool-Interactive Environments for LLM Agent via Programmatic Synthesis

> **作者**: Xiaoshuai Song, Haofei Chang, Guanting Dong, Yutao Zhu, Ji-Rong Wen, Zhicheng Dou  
> **机构**: 中国人民大学  
> **发表**: 2026（预印本）  
> **arXiv**: 2601.05808  
> **代码**: https://github.com/RUC-NLPIR/EnvScaler

## 研究问题

LLM Agent需要在丰富多样的工具交互沙箱中训练，但现实系统访问受限，LLM模拟的环境容易产生幻觉和不一致，人工构建的沙箱难以规模化。如何**自动化地大规模合成工具交互环境**用于Agent训练？

## 困难点

1. **真实系统不可达**：很多API和系统出于安全原因不开放。
2. **LLM模拟不可靠**：用LLM模拟环境存在幻觉和状态不一致问题。
3. **人工沙箱不可扩展**：手动构建每个环境的成本极高。
4. **环境多样性**：需要覆盖不同主题和逻辑的交互环境。

## 解决方法

### EnvScaler框架

两个核心组件：

### 1. SkelBuilder — 环境骨架构建

- **主题挖掘**：从真实世界挖掘多样化的主题（如旅行预订、医疗系统、教育平台等）
- **逻辑建模**：为每个主题设计环境的逻辑结构（API集合、数据模型、状态转换）
- **质量评估**：自动评估生成的环境骨架的完整性和合理性
- 结果：多样化的环境骨架集合

### 2. ScenGenerator — 场景生成

- **任务场景生成**：为每个环境生成多个不同的任务场景
- **验证函数生成**：为每个场景自动生成基于规则的轨迹验证函数
- 验证函数可以自动判断Agent的操作序列是否正确
- 结果：可用于训练和评估的完整场景集合

### 应用于Agent训练

将合成环境和场景用于：
- **监督微调（SFT）**：使用合成轨迹进行行为克隆
- **强化学习（RL）**：使用验证函数作为奖励信号
- 目标模型：Qwen3系列

## 主要结果

- 合成了**191个环境**和约**7,000个场景**
- 在三个benchmark上显著提升了LLM在复杂多轮多工具交互任务中的能力
- SFT和RL训练均展示了有效性
- 证明了程序化合成环境的可行性和有效性

## 对本课题的启示

EnvScaler是**环境合成**方面的代表性工作，其核心贡献在于：
1. **程序化方法**：通过规则和模板生成环境，比纯LLM生成更可靠
2. **验证函数自动生成**：解决了合成数据的质量保证问题
3. **SFT+RL双用途**：合成数据同时支持不同训练范式
4. **可扩展性强**：从191个环境证明了方法的规模化潜力

对于benchmark数据合成，EnvScaler展示了**环境层面的自动合成**与AgentTrek/EvoCUA的**轨迹层面合成**可以互补。
