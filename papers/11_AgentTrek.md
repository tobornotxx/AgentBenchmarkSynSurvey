# AgentTrek: Agent Trajectory Synthesis via Guiding Replay with Web Tutorials

> **作者**: Yiheng Xu, Dunjie Lu, Zhennan Shen, Junli Wang, Zekun Wang, Yuchen Mao, Caiming Xiong, Tao Yu  
> **机构**: HKU, Salesforce Research  
> **发表**: ICLR 2025 Spotlight  
> **arXiv**: 2412.09605

---

## 研究问题

GUI Agent的开发受限于高质量轨迹数据的稀缺。现有方法依赖昂贵的人工标注，如何设计一个**可扩展的、低成本的自动化轨迹合成管线**？

## 困难点

1. **轨迹数据稀缺**：Web Agent训练需要大量"指令-操作序列"对，人工标注成本极高（每条轨迹数十美元）。
2. **多模态需求**：轨迹需要同时包含文本观察（HTML）和视觉观察（截图），以及对应的操作。
3. **质量保证**：自动生成的轨迹可能包含错误操作，需要可靠的验证机制。
4. **任务多样性**：需要覆盖各种类型的Web任务。

## 解决方法

三阶段管线：

### 阶段1：教程收集与过滤
- 从互联网自动收集教程式文本（如"如何在Gmail中创建标签"）
- 训练专用分类模型过滤高质量教程
- 教程提供了任务描述和步骤级指导

### 阶段2：任务规范生成
- 将教程文本转化为结构化的任务规范（task specifications）
- 包含明确的步骤级指令
- 使LLM理解任务目标和执行步骤

### 阶段3：引导回放与验证
- **VLM Agent执行**：使用视觉语言模型Agent在真实Web环境中按照教程指令执行操作
- **VLM评估器验证**：独立的VLM评估器验证轨迹正确性
- 收集多模态轨迹数据（HTML + 截图 + 操作 + 思维链推理）

### 关键创新
- **教程即知识源**：利用互联网上海量的"how-to"教程作为免费的任务知识
- **引导回放**（Guiding Replay）：教程提供步骤级指导，比完全自主探索更可靠
- **多模态输出**：同时生成文本和视觉两种模态的轨迹数据

## 主要结果

- 每条高质量轨迹成本仅**$0.55**（对比人工标注的数十美元）
- 在WebArena（文本Web浏览）上达到SOTA
- 在ScreenSpot Web和Multimodal Mind2Web（视觉Web任务）上达到SOTA
- 全自动化、无需人工标注者

## 对本课题的启示

AgentTrek是**Agent Benchmark数据合成**的标志性工作，展示了：
1. **免费知识源**（互联网教程）可以替代昂贵的人工标注
2. **引导式合成**比完全自主探索更高效
3. **多模态轨迹**可以通过纯自动化管线生成
4. **成本降低了1-2个数量级**

其"知识收集 → 结构化 → 引导执行 → 自动验证"的管线为benchmark数据合成提供了可复用的框架。
